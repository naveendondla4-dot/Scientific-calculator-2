CALC PRO - FULL CASIO-STYLE SCIENTIFIC CALCULATOR

Original app inspired by the workflow of scientific calculators. It does not copy Casio branding or proprietary artwork.

Includes:
Login/Register, SHIFT, ALPHA, MODE, SETUP, DEG/RAD/GRAD, scientific functions, memory, Ans, history, matrix tools, equation solver, statistics, complex arithmetic, table, Base-N, theme and PWA.

Accounts are browser-local. For PWA install, deploy to a static host or use a local web server.
